# GEFS-WAVE

*NOAA/NCEP GEFS-Wave, control member, 0.25 degree*

## Why it matters

The wave model run with the GEFS control member's winds, at 0.25 degrees. A second look at the sea state, a little finer than GFS-Wave; only the control member is shown.
