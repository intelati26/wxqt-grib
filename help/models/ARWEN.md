# ARWEN

*ArWen regional run (WRF history on this computer)*

## Why it matters

ArWen is a GPU regional forecast model you run yourself, for an area or a cyclone you choose. This entry shows the runs it has made on this computer, so they can be put beside the other models (the Compare tiles, including the difference from another model or from the MRMS radar) on the same valid time. Its history files are WRF-format; the run's own Lambert grid is put on latitude / longitude for the charts.

## Further reading

- [ArWen](https://github.com/FahrenheitResearch/arwen) (From the people who run it)

## Where the data is read from

- Folders on this computer: `out/<study>/<run>/run/wrfout` under `~/arwen` or `~/Claude/arwen`; the setting `WRF_FOLDERS_ARWEN` (folders separated by `;`) names others.
