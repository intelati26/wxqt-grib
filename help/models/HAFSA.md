# HAFSA

*NOAA/NCEP HAFS-A, 2 km storm-following grid*

## Why it matters

NOAA's hurricane model, a version run for each active storm on a grid that moves with it at 2 km. It is one of the main sources of track and intensity guidance, and its wind field and structure are what a forecaster reads when a storm is near land. It only exists while there is a storm.
