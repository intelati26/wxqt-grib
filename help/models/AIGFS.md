# AIGFS

*NOAA/NCEP AIGFS 0.25 degree (an AI model; experimental)*

## Why it matters

An experimental NOAA model made by machine learning (it learned from decades of past weather) rather than by solving the physics. It costs a small fraction of the computing of a physical model, so it can be run often; its value here is as a second opinion beside the GFS. It is new and has not been tested in every situation.
