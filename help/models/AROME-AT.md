# AROME-AT

*GeoSphere AROME Austria 2.5 km (via Open-Meteo)*

## Why it matters

GeoSphere Austria's AROME: 2.5 km over Austria and the Alps, a new run every 3 hours, hourly to 60 hours. It is the one to read for how the mountains shape the weather: foehn winds, valley cold pools and the storms that form on the slopes. Surface fields only here. Open-Meteo's copy can lag: when this was written its newest run was over a day old, and the model shows no run while that lasts.
